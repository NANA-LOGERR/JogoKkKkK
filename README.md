## Sobre o projeto
O jogador controla um personagem em uma ilha paradisíaca onde ele tem que coletar esse objeto (coco).  

## O que o projeto faz
O jogador controla um personagem usando as teclas WSAD em uma ilha paradisíaca onde ele tem que coletar esse objeto para ganhar. 

**Scripts:** 
MovimentoPersonagem

**Objetos principais:** 
Sphare, Plane, Cenário, Personagem. 

**Recursos usados:**
MeshCollider, SphareCollider, BoxCollider, CharacterController. 

## Controles
W- vai pra frente
S - Vai para trás 
A- Vai para a direita 
D - Vai para a esquerda
